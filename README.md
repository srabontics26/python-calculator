# Python Calculator

A simple command-line calculator built with Python.

## About the Project

I created this project to practice the fundamentals of Python programming and build a small practical application.

The calculator allows users to perform basic arithmetic operations through the command line.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- User input
- Division-by-zero handling
- Invalid input handling
- Option to perform multiple calculations

## Technologies Used

- Python 3

## How to Run

Make sure Python 3 is installed on your computer.
